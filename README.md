# Fictional coach website

The source of https://djwinn.github.io/second-curriculum/, a small public site for the fictional coach in the Test a feature sample sessions and materials. The "Your materials, before the brand conversation" test imports it in Step 1.

- The home and About pages carry the text of `../material-1-website.md`. Work with me is a short offer page so the importer finds an offer.
- The programme overview (`../material-2-programme.md`) is deliberately not on the site: the test adds it in Step 2.
- Every page says the practice is fictional and asks search engines not to index it.
- To change it, edit these files and copy them to the `djwinn/second-curriculum` repository (GitHub Pages publishes its main branch).
- Avoid "test", "draft", "old" or "copy" in page addresses: the importer skips pages with those words.
